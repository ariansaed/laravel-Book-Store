# E-commerce Platform

A modular e-commerce web application built with Laravel and Livewire.

## Tech Stack
- Laravel, Livewire
- PHP 8.4
- MySQL

## Features
- Admin panel (users, categories, product brands)
- Role-based access control

## In Progress
- Products, cart, and orders
- Payment integration
- Sales reports

## Getting Started
```bash
git clone <your-repo-url>
cd <project-folder>
composer install
npm install && npm run build
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```
